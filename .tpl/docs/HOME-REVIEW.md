# 首页还原复查（1.0.1）

参考：https://aigentx.framer.website/ 。本轮按相同视口对照首屏、四步流程、应用连接图、配方时间轴、团队用例、计费滑轨、平台与可信度区。

## 上一版的问题与原因

上一版把页面可访问、没有溢出和交互可用作为主要验证依据，缺少逐区视觉结构对照。首屏粒子区固定高 810px，使桌面标题下移约 216px；背景受内容容器限制；粒子用硬边圆点和字体绘制，轮廓、密度与光感偏离。应用连接图、配方、团队工作流分别被简化成左右布局、六宫格和列表，属于结构性偏差。

## 修正

- 首屏背景铺满视口，桌面球体组件为 700px，平板 600px，手机 280px；修正球体位置、标题比例与手机断行。
- 球壳使用柔边精灵、透视、深度照明和加色叠加；AI 从参考透明素材采样为 1300 粒子，保留聚拢、旋转、呼吸、点击扰动及滚动散开。
- 连接图改为上下各六个应用，经中央核心汇流；补齐本地图标和流动光束。
- 六个配方改为左右交错时间轴，手机改为单列时间轴。
- 团队切换改为逐节点出现的上升曲线图；计费改为大面积分段滑轨，保留原生键盘与拖动能力。
- 修正区块分隔、流程卡片、平台图片、可用率与安全卡片的比例；中文与英文仍使用本地 MiSans / Poppins。

## 验收范围与限制

1440×1000、834×1180、390×844 和 320×844 检查中英文首页。实际触发粒子点击、滚动回顶、团队切换、滑块两端、信息流暂停及手机菜单。类型、Lint、测试、构建和真实 HTTP 结果以当前源码绑定报告为准。

本轮修正上述主要视觉结构，不声明逐帧一致。噪声分布、部分缓动、按钮像素高光和原站精确节奏仍有差异；系统减少动态效果分支没有实机切换验收。原站平板复取一度超时，其结构同时以已取得的参考 CSS 核对。字体、双语与演示说明按本模板约束适配。素材权利限制继续有效。

## 1.0.2 中文标题行距修正

中文首页主标题原先沿用英文紧凑行距，现按语言设置为 1.25，桌面/平板 44px 字号对应 55px 行高，手机 28px 对应 35px。英文桌面 1.03、手机 1.08 保持原值。三端中文首页无横向溢出；本次只复查标题排版，原 1.0.1 的整站交互证据保留为历史记录。

## 1.0.3 首屏说明与按钮间距

首页段落样式与通用段落重置具有相同优先级，后加载的重置清除了下边距，导致说明贴近按钮。现将首页段落选择器限定在 .ax-home 内，使原设计的桌面/宽平板 24px、窄屏/手机 22px 留白生效，保留响应式段落居中。上次 1.0.2 仅测标题行距，未测说明与按钮的几何距离，因此没有捕获此问题。本次按两者边界实测距离并检查中英文与三端布局。

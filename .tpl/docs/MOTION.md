# 动效清单与参考参数

参考站公开页面及运行实现于 2026-11-02/03 核对。以下是实现目标，实际验收另记报告。

| 区域 | 触发与表现 | 节奏/端差异 |
| --- | --- | --- |
| 首屏粒子球 | 从散点聚拢，AI 字形延后形成，球面缓慢旋转并闪烁 | 聚拢延迟 .15s、1.8s；字形延迟 1.1s、1.7s；旋转 6°/s；桌面 4500、手机 2250 粒子 |
| 粒子离场 | 首屏滚出时按粒子错峰散开并淡出，回顶重组 | 散开距离约 1.9 倍，错峰 .45，平滑 .14 |
| 粒子交互 | 指针视差，点击形成短暂爆散、旋转扰动和字形高光 | 视差约 6°，最多三次扰动，离屏与后台暂停 |
| 首屏网格 | 网格内随机方块渐显渐隐 | 原站 .4s 新增、.8s 入出、停留 1.5s；复刻需对应验证 |
| CTA | 高光沿边框循环，悬浮增强、按压回收 | 移除装饰箭头，保留操作 |
| 运行与能力信息流 | 双向无缝循环，边缘遮罩 | 悬停/聚焦暂停；提供显式暂停；手机保留触控 |
| 四步流程 | 入场、连接光束周期流动、节点呼吸 | 光束约 2.5s，平板双列、手机单列 |
| 平台说明 | 随滚动逐词从暗到亮，回滚反向恢复 | 不采用固定延迟的统一淡入 |
| 集成拓扑 | 节点错峰入场、中央光晕、线路周期信号 | 手机纵向重排 |
| 六张配方 | 错峰入场，悬浮提亮与轻移 | 3/2/1 列适配 |
| 团队用例 | 点击切换说明与节点，节点逐项入场 | 内容退出/进入、信号持续 |
| 用量滑块 | 原生拖动和键盘改变用量与方案，高亮切换 | 首页与价格页保留各自参考演示数据 |
| 平台卡 | 入场及图片悬浮缩放 | 平板双列、手机单列 |
| 可用率 | 90 日柱图、颜色状态与周期亮度 | 数据明确标为演示 |
| 内页信息带 | 横向循环 | 各页保持自身文案 |
| 目录/博客 | 筛选时卡片退出进入并重新排列 | 空结果与加载数量可读 |
| 价格推荐 | 切换方案时高亮条平移、卡片高亮 | 可键盘操作 |
| FAQ | 高度与透明度展开收起 | 第一项初始展开，支持关闭 |
| 联系页 | 销售/支持面板上下淡入淡出 | 表单原生校验，本地状态提示 |
| 菜单与切页 | 菜单展开淡入下移、背景锁定；客户端切页短淡入 | 手机显示菜单，Escape 关闭 |

尊重 prefers-reduced-motion：粒子稳定终态，循环、平滑滚动、缩放及过渡停用。原站精确噪声、抖动与物理曲线是近似重实现，不应据静态截图声明逐帧一致。
